⚙️ 연동 설정

현재는 시뮬레이션 모드입니다. 스킬의 출력 구조(카드 상태 모델 + 일곱 구역)를 그대로 보여주는 데모 응답을 생성합니다. 실제 연동 시에는 /api/component-card 같은 엔드포인트로 관찰 사실을 보내고, 스킬 응답(카드 0/5~5/5, PROVISIONAL/BLOCKED/VERIFIED, 일곱 구역)을 받아 채웁니다.
자리 표시 엔드포인트: POST /api/component-card (body: { partName, targetBoard, observations, photoLink, powerInfo })
이 대시보드는 .hermes/skills/component-integration-card/SKILL.md의 카드 상태 모델과 일곱 구역 출력을 그대로 구현해 보여줍니다. 카드 상태: PROVISIONAL / BLOCKED / VERIFIED, 단계: 0/5 ~ 5/5. 계약 항목 근거: IC·캐리어 분리(항목 4), 출처 우선순위(항목 8), 절대 최대 정격/출처 충돌 5열 표(항목 9·10), 출력 계약(항목 2), 상태 모델(항목 7). 아직 실제 부품은 연결·측정하지 않았으며, 카드 5/5는 전원 인가나 런타임 통합 시험 완료가 아닙니다.
